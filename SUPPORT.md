# Support

For a reproducible defect, open an issue in the affected repository. For a question about the organization or where to start, use [this repository](https://github.com/GuardLatice/.github/issues).

Include your goal, version or commit, operating environment, exact steps, expected result and actual result. Redact secrets and use synthetic data.

For scientific corrections or reproduction discrepancies, use [GuardLatice Sciences](https://github.com/GuardLatice/sciences/issues) and identify the exact publication and artifact version.

Community help is provided without an assumed response-time guarantee. Commercial commitments must be explicitly agreed. Security reports follow [SECURITY.md](SECURITY.md), not public support issues.
