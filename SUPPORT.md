# Get help

Questions are welcome in English and French.

| Topic | Where to go |
|---|---|
| Getting started or discussing an integration | [Discussions](https://github.com/GuardLatice/.github/discussions) |
| A documentation error or reproducible problem | Issues in the affected repository; [organization issues](https://github.com/GuardLatice/.github/issues) for this workspace |
| A scientific correction | [Sciences issues](https://github.com/GuardLatice/sciences/issues) |
| A security vulnerability | [Private reporting](SECURITY.md) |

## Tell us what happened

Include your goal, the page or version involved, the steps you followed and the result you expected. For a scientific correction, identify the public work and the relevant section. A small example is more useful than a large unfiltered log.

Public conversations are visible to everyone. Remove secrets and personal data before posting. Do not attach source code, manuscripts, PDFs, TeX files or archives to this workspace.

Community support has no guaranteed response time. Contracted support follows the terms agreed with the customer.
