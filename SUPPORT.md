# Get help

Ask in English or French. Choose the route that fits your question.

| You need | Start here |
|---|---|
| Help with a page or example | [Ask a question](https://github.com/GuardLatice/.github/discussions/new?category=help) |
| To explore an integration | [Describe your use case](https://github.com/GuardLatice/.github/discussions/new?category=integrations) |
| A research discussion or collaboration | [Discuss a public topic](https://github.com/GuardLatice/.github/discussions/new?category=research) |
| To correct documentation | [Report the page and problem](https://github.com/GuardLatice/.github/issues/new) |
| To correct a public scientific result | [Identify the work and section](https://github.com/GuardLatice/sciences/issues/new) |
| To report a security vulnerability | [Use private reporting](SECURITY.md) |

## Considering an integration?

Describe the task, your environment and the main constraint: deployment, performance, compatibility or confidentiality. A few sentences are enough; you do not need to select a component first.

## Reporting a problem?

Include the page or version, what you expected and what happened. For research, identify the public work and the passage involved. No code or document upload is needed.

Discussions and issues are public. Do not post credentials, customer data, product source code, manuscripts, PDFs, TeX files or archives. For confidential project details, ask how to arrange a private exchange before sharing them here.

Community help has no guaranteed response time. Commercial support applies only under an agreed contract.
