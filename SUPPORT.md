# Get help

Choose the channel that matches your question. English and French are welcome.

| You need to… | Use |
|---|---|
| Find a starting point or discuss an idea | [Organization Discussions](https://github.com/GuardLatice/.github/discussions) |
| Report a reproducible defect | An issue in the affected repository; use [organization issues](https://github.com/GuardLatice/.github/issues) for this repository |
| Report a scientific correction or reproduction discrepancy | [Sciences issues](https://github.com/GuardLatice/sciences/issues) |
| Report a suspected exploitable vulnerability | [Private security reporting](SECURITY.md) |

## A useful report

Describe your goal, component and version, environment, smallest reproduction, and expected versus observed result. For research, identify the exact public work and section. State checks that were not performed.

Use synthetic or redistributable data. Redact credentials and personal information. Public branches, issues and attachments are disclosures; checks after upload cannot undo them.

## Support boundaries

Community help does not carry an assumed response-time guarantee. Commercial support and supported product versions require an explicit agreement. A question, contribution or research citation does not create a commercial commitment.
